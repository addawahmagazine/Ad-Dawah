# আদ দাওয়াহ — ওয়েবসাইট

ত্রৈমাসিক ইসলামী পত্রিকা "আদ দাওয়াহ"-এর সম্পূর্ণ ওয়েবসাইট, সঙ্গে বাংলা সম্পাদনা প্যানেল (Decap CMS)।
কোনো বিল্ড স্টেপ নেই — ফোল্ডারটি আপলোড করলেই সাইট চালু।

```
ad-dawah/
├─ index.html          ← পেজের মার্কআপ
├─ admin/
│  ├─ index.html       ← সম্পাদনা প্যানেল
│  └─ config.yml       ← ⚙️ এখানে গিটহাব রিপোর নাম বসাতে হবে
├─ content/            ← সব কনটেন্ট (প্যানেল এখানেই লেখে)
│  ├─ articles.json      লেখাসমূহ
│  ├─ issues.json        সংখ্যা
│  ├─ authors.json       লেখক
│  ├─ categories.json    বিভাগ
│  ├─ media.json         দাওয়াহ কার্ড, অডিও-ভিডিও, প্রশ্নোত্তর
│  └─ site.json          যোগাযোগ, মূল্য, পেমেন্ট নম্বর
├─ uploads/            ← প্যানেল থেকে আপলোড করা ছবি ও পিডিএফ
├─ assets/             ← styles.css, app.js, favicon
├─ netlify.toml, robots.txt, sitemap.xml
```

## এক-দুই-তিন: চালু করা

### ১. গিটহাবে রিপোজিটরি বানান

github.com-এ নতুন রিপোজিটরি খুলুন (নাম যেমন `ad-dawah`), **Public** রাখুন,
তারপর এই ফোল্ডারের সব ফাইল আপলোড করে দিন (Add file → Upload files → পুরো ফোল্ডার ড্র্যাগ)।

### ২. `admin/config.yml`-এ রিপোর নাম বসান

ফাইলটির চার নম্বর লাইনে আছে:

```yaml
repo: USERNAME/REPO-NAME
```

এটি বদলে আপনার গিটহাব ইউজারনেম ও রিপোর নাম লিখুন, যেমন `repo: abdullah/ad-dawah`।
ব্রাঞ্চের নাম `main` না হয়ে `master` হলে নিচের `branch:` লাইনটিও বদলান।

### ৩. নেটলিফাইতে যুক্ত করুন

Netlify → **Add new site → Import an existing project → GitHub** → রিপো বাছুন।
Build command ফাঁকা, Publish directory `.` — Deploy চাপুন।

### ৪. অ্যাডমিন লগইন চালু করুন (একবারই)

সম্পাদনা প্যানেল গিটহাব দিয়ে লগইন নেয়। এর জন্য একবার সেটআপ লাগে:

1. **গিটহাবে**: Settings → Developer settings → OAuth Apps → **New OAuth App**
   - Application name: `Ad-Dawah CMS`
   - Homepage URL: আপনার নেটলিফাই ঠিকানা, যেমন `https://ad-dawah.netlify.app`
   - Authorization callback URL: `https://api.netlify.com/auth/done`
   - তৈরি করে **Client ID** ও **Client Secret** কপি করুন।
2. **নেটলিফাইতে**: Site configuration → Access & security → **OAuth** → Install provider → GitHub —
   কপি করা Client ID ও Secret বসিয়ে সেভ করুন।

এবার `https://আপনার-সাইট.netlify.app/admin/` খুললে "Login with GitHub" বোতাম আসবে।

## লেখা যোগ করা

`/admin/` খুলুন → বাঁ পাশে **লেখাসমূহ** → **সব লেখা** → নিচে **নতুন লেখা**।

ঘরগুলো:

| ঘর | কী লিখবেন |
|---|---|
| শিরোনাম | লেখার নাম |
| লিংক-নাম | ইংরেজি অক্ষরে অনন্য নাম, যেমন `khatme-nubuwat` |
| সংক্ষিপ্তসার | কার্ডে যে দুই-তিন লাইন দেখাবে |
| বিভাগ / লেখক / সংখ্যা | তালিকা থেকে বেছে নিন |
| পড়ার সময় | আনুমানিক মিনিট |
| হোমপেজের প্রধান লেখা | প্রতি সংখ্যায় একটিতেই চালু রাখুন |
| মূল লেখা | নিচে দেখুন |

**মূল লেখা** অংশে "নতুন অংশ" চাপলে চার ধরনের ব্লক বেছে নেওয়া যায়:

- **অনুচ্ছেদ** — সাধারণ প্যারা
- **উপশিরোনাম** — লেখার ভেতরের হেডিং
- **খণ্ডন (দাবি ও জবাব)** — পত্রিকার নিজস্ব ব্লক; দাবিটি সোনালি ঘরে, জবাব সবুজ ঘরে
- **উদ্ধৃতি** — আয়াত বা হাদীস, সঙ্গে সূত্র

যত খুশি ব্লক যোগ করা যায়, ড্র্যাগ করে ক্রম বদলানো যায়।

শেষে উপরের **Publish** চাপুন। নেটলিফাই এক-দুই মিনিটে সাইট আপডেট করে দেবে।

## ফর্মগুলো

তিনটি ফর্ম Netlify Forms-এ যুক্ত: `jiggasha` (আপনার জিজ্ঞাসা), `order` (ছাপা কপির অর্ডার), `subscribe` (ইমেইল)।
জমা পড়া বার্তা দেখবেন Netlify ড্যাশবোর্ডের **Forms** ট্যাবে।
ইমেইলে খবর পেতে: Site configuration → Forms → Form notifications।

## নিজের কম্পিউটারে দেখতে

`index.html`-এ ডাবল ক্লিক করলে কাজ করবে না — ব্রাউজার নিরাপত্তার কারণে `content/` ফোল্ডার পড়তে দেয় না।
ফোল্ডারে টার্মিনাল খুলে চালান:

```
npx serve            # অথবা
python3 -m http.server
```

তারপর `http://localhost:3000` (বা `8000`) খুলুন।
প্যানেলও লোকালি পরীক্ষা করা যায় — আলাদা টার্মিনালে `npx decap-server` চালিয়ে `localhost:3000/admin/` খুলুন।

## ডিপ্লয়ের আগে যা বদলাতে হবে

- `admin/config.yml` — `repo:` লাইন (এটি না বদলালে প্যানেল কাজ করবে না)
- `index.html` — `canonical` ও `og:url`-এর ঠিকানা
- `robots.txt`, `sitemap.xml` — ডোমেইন
- বাকি সবকিছু `/admin` থেকেই বদলানো যাবে

# সংযোজন — প্রথম দফা

## নতুন যা যুক্ত হলো

- **লেখার থাম্বনেইল** — প্রতিটি লেখায় ছবি দেওয়া যায়। না দিলে বিভাগের রঙে জ্যামিতিক নকশা তৈরি হয়।
- **প্রকাশিতব্য সংখ্যার প্রি-অর্ডার** — সংখ্যাসমূহে "প্রি-অর্ডার নেওয়া হচ্ছে" চালু করলে হোমপেজে আলাদা ব্যানার দেখাবে।
- **বিজ্ঞাপন** — দুটি জায়গা: লেখার তালিকার নিচে ও আর্কাইভের আগে। চালু বিজ্ঞাপন না থাকলে জায়গাটি লুকিয়ে যায়।
- **এজেন্ট ও মাকতাবা** — নাম, ঠিকানা, ফোন, গুগল ম্যাপ; ধরন ও জেলা ধরে ছাঁকনি।
- **লেখা পাঠান** — পাঠকের লেখা জমা নেওয়ার ফর্ম, Word/PDF সংযুক্তিসহ।
- **স্বাগত বাণী** — সাইটে ঢোকার সময় আয়াত/হাদীসের পপআপ।
- **সাজানোর ছাঁকনি** — সর্বশেষ আগে / পুরোনো আগে / শিরোনাম অনুসারে।
- **আমাদের সম্পর্কে** এখন প্যানেল থেকে সম্পাদনাযোগ্য।
- **লেখকের ছবি** ও **দাওয়াহ কার্ডে ছবি**।
- লেখার ভেতরে **ছবি ব্লক** যোগ করা যায়।

# সংযোজন — দ্বিতীয় দফা (লগইন ও পরিসংখ্যান)

## এক. Supabase প্রজেক্ট তৈরি

supabase.com → GitHub দিয়ে সাইন আপ → **New project**।
নাম `ad-dawah`, Region **Southeast Asia (Singapore)**, প্ল্যান Free।
ডাটাবেস পাসওয়ার্ডটি কোথাও লিখে রাখুন।

## দুই. টেবিল তৈরি

Supabase → বাঁ পাশে **SQL Editor** → **New query** →
`supabase/schema.sql` ফাইলের পুরো লেখা কপি করে পেস্ট → **Run**।
একবারই চালাতে হবে।

## তিন. চাবি দুটি বসানো

Supabase → **Project Settings → API** থেকে দুটি জিনিস কপি করুন:

- **Project URL** (https://xxxx.supabase.co)
- **anon / public key**

`assets/config.js` ফাইলে বসিয়ে দিন:

```js
window.SUPA = {
  url: "https://xxxx.supabase.co",
  key: "eyJhbGciOi..."
};
```

anon key সাইটে রাখা নিরাপদ — এটি সবার জন্য উন্মুক্ত।
**service_role key কখনও এখানে বসাবেন না।**

ঘর দুটি ফাঁকা থাকলে সাইট আগের মতোই চলবে, শুধু লগইন ও পরিসংখ্যান লুকানো থাকবে।

## চার. ইমেইল নিশ্চিতকরণ

Supabase → **Authentication → Providers → Email** — এখানে
“Confirm email” চালু থাকলে নিবন্ধনের পর পাঠক ইমেইলের লিংকে ক্লিক করে
অ্যাকাউন্ট নিশ্চিত করবেন। শুরুতে পরীক্ষার সুবিধার্থে এটি বন্ধ রাখতে পারেন।

**Authentication → URL Configuration**-এ Site URL হিসেবে আপনার
নেটলিফাই ঠিকানাটি বসিয়ে দিন, নইলে পাসওয়ার্ড রিসেটের লিংক কাজ করবে না।

ফ্রি প্ল্যানে Supabase-এর নিজস্ব ইমেইল সেবায় ঘণ্টায় অল্প কয়েকটি ইমেইল
পাঠানো যায়। পাঠক বাড়লে **Authentication → Emails → SMTP Settings**-এ
নিজের SMTP (যেমন Brevo বা Resend) যুক্ত করতে হবে।

## প্রশ্নের জবাব দেওয়া

পাঠকের প্রশ্ন দুই জায়গায় জমা হয় — Netlify Forms (আপনার ইমেইল নোটিফিকেশনের
জন্য) এবং Supabase-এর `questions` টেবিল (পাঠক যাতে নিজের প্রশ্ন ও জবাব
দেখতে পান)।

জবাব দিতে: Supabase → **Table Editor → questions** → সংশ্লিষ্ট সারির
`answer` ঘরে জবাব লিখুন এবং `answered` ঘরে টিক দিন। পাঠক লগইন করলে
তাঁর অ্যাকাউন্ট পাতায় জবাবটি দেখতে পাবেন।

## এখনও বাকি (তৃতীয় দফা)

পুরোনো সংখ্যার পিডিএফ বিক্রি — অর্ডার, ট্রানজেকশন আইডি যাচাইয়ের
অ্যাডমিন পাতা এবং কেনা পিডিএফের সুরক্ষিত ডাউনলোড।

---

# সংযোজন — তৃতীয় দফা (পিডিএফ বিক্রি)

## এক. ডাটাবেস প্রস্তুত

Supabase → **SQL Editor → New query** → `supabase/schema-2.sql` ফাইলের পুরো
লেখা পেস্ট করে **Run**।

## দুই. নিজেকে প্রশাসক বানান

একই ফাইলের একদম শেষে তিনটি লাইন মন্তব্য করা আছে (শুরুতে `--` চিহ্ন)।
ইমেইলটি বদলে নিজের ইমেইল বসান, `--` চিহ্নগুলো মুছে দিন, তারপর ওই তিনটি
লাইন আলাদাভাবে **Run** করুন।

এরপর সাইটে লগইন করে অ্যাকাউন্ট পাতা খুললে নিচে **“অপেক্ষমাণ অর্ডার”**
অংশটি দেখতে পাবেন। এটি কেবল প্রশাসকের চোখেই পড়ে।

## তিন. পিডিএফ কোথায় রাখবেন

দুই রকম সংখ্যা থাকতে পারে:

**বিনামূল্যের সংখ্যা** — প্যানেলে “পিডিএফ ফাইল” ঘরে আপলোড করুন, দাম ০ রাখুন।
আগের মতোই সবাই নামাতে পারবে।

**বিক্রির সংখ্যা** — প্যানেলে “পিডিএফের দাম” ঘরে দাম বসান (যেমন ৫০) এবং
“পিডিএফ ফাইল” ঘরটি **ফাঁকা রাখুন**। ফাইলটি আপলোড করতে হবে Supabase-এ:

Supabase → **Storage → issues** বাকেট → **Upload file** →
ফাইলের নাম হতে হবে ঠিক সংখ্যার আইডি অনুযায়ী — যেমন `y1n1.pdf`, `y1n2.pdf`।

নামটি না মিললে ক্রেতা ফাইল পাবেন না।

## চার. বিক্রির প্রক্রিয়া

1. পাঠক লগইন করে আর্কাইভে **“পিডিএফ কিনুন ৳৫০”** চাপেন
2. বিকাশ/নগদে টাকা পাঠিয়ে ট্রানজেকশন আইডি জমা দেন
3. আপনি অ্যাকাউন্ট পাতায় **অপেক্ষমাণ অর্ডার**-এ সেটি দেখেন
4. বিকাশ অ্যাপে মিলিয়ে **অনুমোদন** বা **বাতিল** চাপেন
   (বাতিল করলে কারণ লিখতে বলা হবে, ক্রেতা সেটি দেখতে পাবেন)
5. অনুমোদনের সঙ্গে সঙ্গে ক্রেতার অ্যাকাউন্টে পিডিএফটি যুক্ত হয়ে যায়

## নিরাপত্তা

পিডিএফগুলো **সুরক্ষিত বাকেটে** থাকে — সরাসরি লিংক দিয়ে কেউ নামাতে পারে না।
ক্রেতা যখন “নামান” চাপেন, তখন তাঁর জন্য **১০ মিনিটের একটি সাময়িক লিংক**
তৈরি হয়। ওই লিংক অন্য কাউকে পাঠালেও ১০ মিনিট পর অকেজো হয়ে যায়।

ডাটাবেসের নিয়মে বাঁধা আছে — পাঠক নিজের নামে কেবল “অপেক্ষমাণ” অর্ডারই
তৈরি করতে পারেন, নিজে থেকে “অনুমোদিত” করতে পারেন না। অবস্থা বদলানোর
অনুমতি কেবল প্রশাসকের।

## ভবিষ্যতে স্বয়ংক্রিয় করতে

ট্রেড লাইসেন্স করে নিলে SSLCommerz বা aamarPay যুক্ত করা যাবে। তখন
ধাপ ৩ ও ৪ লাগবে না — টাকা পৌঁছালেই পিডিএফ খুলে যাবে। বর্তমান কাঠামোটি
সেভাবেই বানানো, কেবল অনুমোদনের অংশটি গেটওয়ের হাতে দিতে হবে।
